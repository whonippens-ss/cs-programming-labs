# Лабораторная работа 6. Реализация численных алгоритмов

## Задание 1. Наибольший общий делитель

Программа запрашивает два целых числа `a` и `b`, каждое вводится с новой строки. Если введено отрицательное число или оба значения равны нулю, необходимо вывести «Ошибка». Для всех остальных случаев нужно вычислить наибольший общий делитель, используя алгоритм Евклида.

**Файл:** `task1.py`

## Задание 2. Проверка числа на простоту

С клавиатуры вводится целое число `n`. Требуется проверить его на простоту, для чего нужно перебрать возможные делители от 2 до квадратного корня из `n`. В зависимости от результата вывести «Простое» или «Не простое».

**Файл:** `task2.py`

## Задание 3. Разложение на простые множители

Пользователь вводит целое число `n`. Если число меньше 2, выводится «Ошибка». В противном случае необходимо разложить число на простые множители и напечатать их в порядке возрастания, разделяя одним пробелом.

**Файл:** `task3.py`

## Задание 4. Цифры числа

Вводится целое число `n`. Если оно отрицательное — вывести «Ошибка». Для корректно введенного числа нужно посчитать количество цифр в нем, а также найти сумму этих цифр.

**Файл:** `task4.py`

## Задание 5. Таблица расстояний

Пользователь вводит целое число `n` в диапазоне от 1 до 10 включительно. Если число выходит за эти рамки, выводится «Ошибка». Для допустимого `n` нужно сформировать таблицу расстояний для всех пар точек, координаты которых являются целыми числами от 0 до n - 1.

**Файл:** `task5.py`
