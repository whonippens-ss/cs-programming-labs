# Лабораторная работа 8. Функции

## Задание 1. Посадка лунного модуля

Написать консольную игру, в которой пользователь по шагам управляет двигателем лунного модуля и должен посадить его на поверхность с безопасной скоростью, распределяя ограниченный запас топлива. Программа разбита на функции:

- `is_valid_command(command)` — проверка, что введенная строка является допустимой командой (`'0'`, `'1'`, `'2'`, `'exit'`);
- `can_burn(power, fuel)` — проверка, хватает ли оставшегося топлива на шаг с выбранной мощностью двигателя;
- `simulate_step(height, speed, fuel, power, gravity, thrust_step)` — расчет одного шага полета: расход топлива, новая скорость с учетом гравитации и тяги, новая высота;
- `get_status(height, speed, safe_speed=2)` — определение состояния модуля: «В полете», «Посадка успешна» при касании поверхности со скоростью ≤ 2 или «Авария» при большей скорости;
- `format_state(height, speed, fuel)` — формирование строки с текущей высотой, скоростью и остатком топлива;
- `main()` — основной цикл игры: ввод команд, вызов остальных функций, вывод результата, обработка ошибок ввода и нехватки топлива, завершение при посадке, аварии или команде `exit`.
