# Лабораторная работа 7. Обработка списков и таблиц

В рамках данной лабораторной работы необходимо реализовать пять задач по обработке одномерных списков и двумерных таблиц (матриц) на языке Python. Каждое задание должно быть оформлено в отдельном файле. Использование списков обязательно для хранения и обработки данных.

---

## Задание 1. Корректировка остатков

**Описание:** 
Считать строку с целыми числами, которые обозначают остатки товаров. Необходимо создать копию исходного списка и заменить в ней все отрицательные значения на нули. Замена должна выполняться с помощью присваивания по индексу. Исходный список при этом должен остаться неизменным.

**Вывод:** 
В консоль выводятся исходный и исправленный списки в формате примеров.

**Файл:** `task1.py`

---

## Задание 2. Отбор значений

**Описание:** 
Считать список целых чисел. С использованием спискового включения (list comprehension) сформировать новый список, состоящий из квадратов положительных нечетных чисел. Важно сохранить исходный порядок следования элементов и их повторения. Если подходящих чисел нет, результатом должен быть пустой список.

**Вывод:** 
Полученный список квадратов.

**Файл:** `task2.py`

---

## Задание 3. Индексы совпадений

**Описание:** 
На первой строке считывается список целых чисел, на второй — искомое число. Необходимо создать список индексов всех элементов, которые равны искомому числу. Индексы должны идти в порядке возрастания. Для реализации обязательно использовать функцию `enumerate()` с нумерацией от `0`. При отсутствии совпадений вывести пустой список `[]`.

**Вывод:** 
Список найденных индексов.

**Файл:** `task3.py`

---

## Задание 4. Суммы строк и столбцов

**Описание:** 
Первая строка ввода содержит размеры таблицы: количество строк `r` и столбцов `c`. Далее следуют `r` строк, в каждой из которых ровно `c` целых чисел. Необходимо сохранить таблицу в виде списка списков. Вычислить суммы элементов каждой строки и каждого столбца, используя накопление в циклах.

**Вывод:** 
Два списка: суммы по строкам и суммы по столбцам (порядок элементов должен соответствовать порядку строк и столбцов).

**Файл:** `task4.py`

---

## Задание 5. Поиск в области таблицы

**Описание:** 
Сначала считывается таблица (размеры `r` и `c`, затем сами элементы). После таблицы вводится строка с четырьмя числами: `row_start`, `row_end`, `column_start`, `column_end`. Они задают прямоугольную область с включенными границами (индексация с `0`). На последней строке вводится искомое число.
Необходимо найти все ячейки с этим значением внутри заданной области. Обход области выполняется сверху вниз, а внутри строки — слева направо.

**Вывод:** 
Для каждого совпадения на отдельной строке выводятся индекс строки и индекс столбца через пробел. Если совпадений нет, вывести `Не найдено`.

**Файл:** `task5.py`

---

## Общие требования к выполнению

*   Каждое задание оформляется в отдельном `.py` файле.
*   Входные данные считаются корректными, проверка на ошибки ввода не требуется.
*   Для ввода использовать функцию `input()` **без** приглашения к вводу (текста в скобках).
*   Вывод результатов должен строго соответствовать формату, приведенному в примерах заданий.
*   Хранение и обработка данных должны осуществляться исключительно с помощью списков.
